Frequently Asked Questions

Does JSON validation report the error position?

Yes. When the JSON syntax is invalid, the tool parses the error message and works out the exact line and column, helping you locate the problem quickly.

What path format does path query support?

It supports path syntax like $.store.book[0].title: object properties use dots and array elements use bracket indexes. Enter a path and click Locate to highlight the matching node.

Can I copy the value or path of a node directly?

Yes. Hover over any node row and two buttons appear, Copy Value and Copy Path, which copy the node JSON value and the full path string respectively.
