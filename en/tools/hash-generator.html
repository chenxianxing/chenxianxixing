Frequently Asked Questions

Why does the SHA family fail when the file is opened directly (file://)?

The SHA family uses the browser Web Crypto API (crypto.subtle), which is only available in secure contexts (https or http://localhost). If you open the file directly by double-clicking it (the address bar shows file://), the browser disables crypto.subtle. The solution is to access it through a local server, for example run python -m http.server inside the directory and then open http://localhost.

Is MD5 safe? What can it still be used for?

MD5 has proven collision vulnerabilities and must not be used for security signatures or password storage, but it is still suitable for ordinary file integrity checks (such as comparing downloaded files) or non-security digests. The MD5 in this tool is a pure JavaScript implementation that requires no external libraries.

What is the difference between HMAC and a regular hash?

HMAC (hash-based message authentication code) introduces a key into the hash computation, so only parties holding the same key can verify data integrity, which prevents tampering. A regular hash has no key and anyone can recompute it. HMAC is commonly used for API signing and request verification.
