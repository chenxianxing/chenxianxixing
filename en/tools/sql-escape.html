SQL Escape

Online SQL string escaping and IN list generation tool supporting single-quote doubling, backslash and control character escaping, unescaping, and one-click IN list generation from multi-line text.

Note: escaping converts ' into ''，\ into \\, and line break/carriage return/tab/NUL into \n \r \t \0. Unescape reverses the process. Checking Wrap result in single quotes encloses the whole result in single quotes.

Note: blank lines and leading/trailing whitespace are removed automatically, each item is wrapped in single quotes and joined with commas into a single line, ready to use in IN (...) conditions.

Frequently Asked Questions

Why escape SQL strings?

A single quote inside a string can break the SQL statement structure and even lead to SQL injection. Writing single quotes as two single quotes ('') is the most basic escaping method and ensures the string is parsed correctly by the database.

How are control characters such as line breaks and tabs escaped?

The tool escapes actual line breaks, carriage returns, tabs and NUL characters into the text forms \n, \r, \t and \0 respectively, and escapes the backslash itself as \\, so the result can be written safely into SQL statements.

What is IN list generation for?

It automatically turns one value per line into a comma-separated form like 'a','b','c' that can be pasted directly into an IN (...) condition, removing blank lines and adding quotes automatically.
