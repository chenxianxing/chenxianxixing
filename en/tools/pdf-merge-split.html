Frequently Asked Questions

Does the PDF merge and split tool upload my files?

No. All reading, merging, splitting, and rotating operations run locally in your browser. Files are never uploaded to any server, so it is suitable for documents containing private or confidential content.

What is the page count of a merged PDF?

The merged result concatenates files in list order, and the total page count equals the sum of all files. You can reorder files in the list before merging, and you can also set a uniform rotation angle for all pages of a file.

Can encrypted or corrupted PDFs be processed?

Encrypted (password-protected) or severely corrupted PDFs cannot be parsed, and the tool will show a friendly notice. Please remove password protection first, or use an intact, undamaged file before proceeding.
