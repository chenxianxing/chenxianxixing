Base Converter

Online number base converter supporting binary, octal, decimal, hexadecimal and any base from 2 to 36, with negative number and BigInt support, plus a byte HEX view. All calculations run locally in your browser.

Extra: Byte HEX View

Encode text into UTF-8 bytes and display them as two-digit hexadecimal groups, or convert HEX back to text.

Frequently Asked Questions

How do I enter hexadecimal or binary numbers?

The tool parses input according to the source base you select. Choose Hexadecimal and you can enter FF or 0xFF; choose Binary and you can enter 1010 or 0b1010; choose Octal and you can enter 17 or 0o17. Input containing characters that are invalid for the selected base will show an error.

How large can the numbers be? Are negative numbers supported?

This tool uses BigInt for arbitrary-precision integer arithmetic. In theory it is limited only by browser memory, so it can handle very large integers with dozens or even hundreds of digits. Negative numbers starting with a minus sign are also supported.

What is the byte HEX view for?

It encodes text into UTF-8 bytes and displays them as two-digit hexadecimal groups (e.g. Hello becomes 48 65 6C 6C 6F), which is useful for inspecting the underlying bytes of a string. The reverse is also supported: paste HEX to restore it as text.
