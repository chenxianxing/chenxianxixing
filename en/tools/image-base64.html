Frequently Asked Questions

What is the point of converting images to Base64?

Base64 can embed images directly into HTML, CSS or JSON, cutting extra network requests for small icons or multi-image pages and making single-file sharing and offline display easier. The trade-off is that the size grows by roughly 33% over the original file.

Could my images be leaked during conversion?

No. All reading, encoding and decoding is done locally in your browser via FileReader; images are never uploaded to any server, so this is suitable for sensitive images.

How does the tool determine the image type from pasted Base64?

If the pasted content starts with data:, the MIME type inside it is used directly; for pure Base64, the tool automatically recognizes common formats such as PNG, JPEG, GIF and WEBP from the file header. If recognition fails, it falls back to PNG and shows a notice.
