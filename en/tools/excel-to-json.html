Frequently Asked Questions

Which file formats are supported?

Three formats are supported: .xlsx, .xls and .csv. Files are uploaded via selection or drag-and-drop, and parsing is done entirely locally in your browser; nothing is sent to any server.

What does the first-row header option do?

When checked, the first row is used as the field names and the output is an array of objects keyed by the header; when unchecked, the output is a 2D array, which suits header-less raw data tables.

Can I convert JSON back to Excel?

Yes. In the JSON to Excel mode, paste an array of objects and click generate to download the .xlsx file; column names come from the keys of the first object.
