JSON/YAML/TOML Converter

Online converter between JSON, YAML and TOML, supporting JSON to YAML, JSON to TOML, YAML to JSON, YAML to TOML, TOML to JSON and TOML to YAML. It auto-detects pasted content, reports errors with line numbers, and performs all conversions locally in your browser.

Comparison of the three config formats

FormatSyntax styleCommentsTypical uses
JSON Double-quoted keys wrapped in braces, comma separated, the strictest Not supported API data exchange, client-server transfer
YAML Indentation expresses hierarchy, key and value separated by a colon and space Supports # comments Config files, CI/CD pipelines, Kubernetes
TOML Key = value, with [table] and [[array of tables]] for hierarchy Supports # comments Project configs (Cargo.toml, pyproject.toml)

Note: All conversions run locally in your browser and no data is uploaded.TOML and YAML output is always pretty-printed; JSON output can switch between indented and compact via Pretty output. When parsing fails, the field name and line number are shown to help you locate the problem quickly.

Frequently Asked Questions

Does converting between the three formats lose data?

JSON, YAML and TOML all support strings, numbers, booleans, arrays and nested objects, so regular structures convert without data loss. Note that TOML has no null type and reports an error on null values; TOML datetimes are kept as strings; advanced YAML features such as anchors and aliases are expanded into plain structures during conversion.

Why is there a null error when converting to TOML?

The TOML specification has no null type, which keeps its type system deterministic. When converting JSON or YAML to TOML, if the data contains null the tool points out the offending key; please remove that key or change its value to an empty string, 0, etc.

Is the conversion done on a server?

No. All parsing and generation happen locally in your browser. The page makes no network requests and your input is never uploaded to any server, so it is safe for configuration data containing sensitive information.
