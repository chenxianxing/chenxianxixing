Frequently Asked Questions

What input formats does the tool support?

It supports full URLs (the query part after the question mark is extracted automatically), query strings with a question mark (e.g. ?a=1&b=2), and bare parameter strings without one (e.g. a=1&b=2). A #hash fragment in the URL is preserved separately and is not treated as a parameter.

What does the encoding toggle do?

When on, every parameter value is encoded with encodeURIComponent while rebuilding the URL, which is suitable for direct use in requests; when off, values are concatenated as-is, which is suitable for viewing or building readable links with Chinese/special characters. The parameter table also marks whether each row is currently URL-encoded.

What happens if the pasted URL contains a #hash?

The tool correctly recognizes the part after # as the hash (fragment identifier) and preserves it separately, without mixing it into the parameters. The rebuilt URL also appends the hash unchanged at the end.
