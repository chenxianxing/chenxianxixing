Frequently Asked Questions

What does the Generate complete HTML document option do?

When checked, the conversion result includes the complete HTML document structure (<!DOCTYPE html>, head, meta and embedded basic typography styles), ready to save as a .html file and open in a browser. When unchecked, only the HTML fragment inside the body is output, which is convenient for embedding into existing pages.

Is the converted HTML safe?

Markdown natively supports raw HTML, so the conversion preserves whatever you write. Since everything is done locally in the browser with no upload, it is suitable for your own documents; if you convert Markdown from untrusted sources, please check it for script tags before inserting it into a web page.

Which common syntaxes does Markdown support?

Common syntaxes include headings (#), emphasis (**bold** / *italic*), lists (ordered and unordered), links and images, inline and block code, tables and quotes (>). A complete cheat sheet is provided at the bottom of the page.
