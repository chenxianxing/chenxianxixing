Token Generator

Online random token/secret/API key generator using browser crypto secure random numbers, supporting Hex, Base64 and Base64URL formats and batch generation. All computation is done locally and nothing is uploaded.

🔒 Security note: All tokens are generated locally in your browser and never travel over the network or get stored on a server. Please keep generated secrets safe and rotate them immediately if leaked. Never store them in plaintext in public code repositories or logs.
When to use each format:
• Hex (hexadecimal): best compatibility, can be stored directly in a database or printed in logs, but twice the length of the raw bytes; suitable as a random salt or device fingerprint.
• Base64: about 1/3 smaller than Hex, commonly used in config files or network transmission, but not suitable for direct use in URLs.
• Base64URL: replaces + and / Replace with - and _, and removes the trailing padding =, made for URLs, JWT payloads or file names, and will not be escaped.

Frequently Asked Questions

How do I choose between Hex, Base64 and Base64URL?

Hex (hexadecimal) has good compatibility and can be used directly in databases or logs, but is twice the size of the raw bytes; Base64 is smaller and commonly used for configuration or transmission; Base64URL replaces + and / with - and _ and drops the = padding, making it suitable for URLs, JWTs or file names without escaping.

Are the generated tokens secure?

This tool uses the browser built-in cryptographically secure random number generator crypto.getRandomValues, so the output cannot be predicted. Everything is generated locally and never uploaded. Please keep the results safe and rotate keys immediately if they are leaked.

How long does a token need to be to be secure?

For session tokens or API keys, at least 32 bytes (256 bits) of random entropy is recommended; 16 bytes is acceptable for short-term or low-sensitivity scenarios. Longer output means a harder brute-force attack. Please avoid reusing the same token for different purposes.
