CSS Gradient Generator

Online CSS gradient code generator supporting linear, radial and conic gradients. Visually adjust the angle, shape, position and multiple color stops, preview in real time and copy ready-to-use CSS code with one click.

Note: The stop position is the percentage of the gradient occupied by that color. Click the color picker or type a HEX value directly. The copied CSS is the background property; paste it straight into the style of the target element to apply it.

Frequently Asked Questions

What is the difference between linear and radial gradients?

A linear gradient transitions along a straight line (its direction is controlled by the angle), which suits diagonal or top-to-bottom transitions; a radial gradient spreads outward from the center as a circle or ellipse, ideal for glows and button highlights; a conic gradient sweeps its colors around the center point.

How do I use the generated CSS code directly?

Copy the generated background property and paste it into the CSS rule of the target element. Virtually all modern browsers natively support linear-gradient, radial-gradient and conic-gradient.

How many color stops can I set?

There is no fixed limit on the number of color stops. The tool provides two by default; click Add Color Stop at any time to add more, or delete extra stops. Keep at least two for a valid gradient.
