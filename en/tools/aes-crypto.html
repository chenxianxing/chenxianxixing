Frequently Asked Questions

Is the AES encryption passphrase secure?

The passphrase is derived into an encryption key through 100,000 PBKDF2-SHA256 iterations, combined with a randomly generated salt and IV each time, which effectively resists brute-force attacks. All operations run locally in your browser, and the passphrase is never uploaded to the server in any form.

What is the difference between AES-GCM and AES-CBC? Which should I choose?

AES-GCM is an authenticated encryption mode that not only keeps data confidential but also detects tampering, so it is recommended. AES-CBC is a traditional block cipher mode whose security relies on correct padding and a random IV. This tool uses a self-describing ciphertext format, so you do not need to choose a mode when decrypting.

Can I recover the plaintext if I forget the passphrase?

No. The key is generated from the passphrase through a one-way derivation algorithm, with no backdoor or server storage. Please keep your passphrase safe after encryption. Forgetting it means the plaintext cannot be recovered, which is also a security feature of local encryption.
