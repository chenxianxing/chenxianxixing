Frequently Asked Questions

What are HTML entities for, and when do you need to escape?

HTML entities safely represent special characters in web pages. For example, <, > and & have syntactic meaning in HTML; written directly, the browser parses them as tags or entities, so they must be escaped as &lt;, &gt; and &amp;. In addition, some rare symbols and copyright, trademark and similar signs are often represented as entities to ensure correct display across encodings.

What is the difference between decimal and hexadecimal entities?

Both represent the same Unicode code point, only the base differs: decimal is written as &#233;, hexadecimal as &#xE9;. They render exactly the same character, so the choice depends on personal or team preference. This tool lets you switch freely when encoding.

What happens to unrecognized entities during decoding?

This tool supports named entities, decimal and hexadecimal numeric entities. Unrecognized entity names or malformed entities are kept as-is in the result without incorrect substitution or dropping, so you can inspect the original text.
