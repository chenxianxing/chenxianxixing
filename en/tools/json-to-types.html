Frequently Asked Questions

      

        
What is generated when array elements have inconsistent types?

        
The tool iterates over every element in the array and merges their fields and types. When different types appear at the same position, it generates a union type, for example [1, "a"] is inferred as number | string; an empty array outputs any[] (or the nullable/any type of the target language).

      

      

        
How are nested objects handled?

        
Nested objects are processed recursively and produce named sub-types: TypeScript emits a standalone interface or type, Go emits a standalone struct and preserves the original field names via json tags, Python emits a standalone TypedDict, and Rust emits a standalone struct with serde derives.

      

      

        
What if a key is not a valid identifier?

        
TypeScript quotes invalid identifier keys (e.g. "foo-bar"); Go converts field names to PascalCase and preserves the original keys via json tags; Python and Rust convert to snake_case. This makes the generated code both valid and able to map back to the original JSON keys during serialization.
