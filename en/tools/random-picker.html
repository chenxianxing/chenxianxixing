Frequently Asked Questions

Is the wheel draw result fair?

Yes. The wheel uses the browser's native crypto random number to pick one sector with equal probability, so every item has the same chance and the result is unpredictable. Enabling fair seed mode switches to a deterministic algorithm for reproducible demos.

What is fair seed mode for?

With the same seed, the results of random draw, dice and coin flip will be identical, which is handy for classroom demos or reproducing a specific result. Without it, true crypto random is used and results differ each time.

What algorithm ensures unbiased random numbers?

By default it uses Web Crypto's crypto.getRandomValues with rejection sampling, ensuring every integer is equally probable and unbiased; seed mode switches to the mulberry32 pseudo-random algorithm for reproducibility.
