Frequently Asked Questions

Can User-Agent strings identify every browser accurately?

UA strings are declared by the browser itself and can theoretically be forged, so parsing is a best-effort identification based on string patterns. Common browsers (Chrome, Firefox, Safari, Edge, WeChat/QQ built-in browsers, etc.) are identified reliably; for niche or heavily customized browsers, only the engine level may be recognized. All matching in this tool uses local regular expressions and no information is uploaded.

How can I tell whether a visitor is a crawler or bot?

The tool checks whether the UA contains typical crawler identifiers such as Googlebot, Baiduspider, Bingbot, Yandex, Bytespider or Shenma, or the generic keywords Spider/Crawler/Bot. If matched, it is flagged as a crawler bot, which helps with statistics or anti-bot analysis.

Why do different browsers on the same computer write the engine differently?

Modern browsers are mostly based on Chromium (the Blink engine), but the UA retains legacy compatibility fields (such as the Safari version and AppleWebKit identifier). The tool synthesizes these fields and prefers the real product name (such as Edge or Chrome) over the engine name, giving a product judgment closer to reality.
