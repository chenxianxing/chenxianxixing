Frequently Asked Questions

Will SVG compression break the graphic?

This tool only removes comments, declarations, metadata and editor-specific attributes such as Inkscape / Sodipodi, and rounds coordinate values. It does not change path command letters (M, C, L, etc.) or the graphic structure, so rendering is usually unaffected. We recommend previewing after compression, and you can adjust precision to balance size and accuracy.

How should I choose the precision?

Precision means the number of digits after the decimal point. For small graphics such as icons, 1-2 digits is usually enough and yields a smaller file; for detailed illustrations, 2-3 digits is preferable. A precision of 0 rounds coordinates to integers and may visibly change shapes, so use it with caution.

Will the compressed file be uploaded?

No. All parsing, compression and downloading happen locally in your browser. Your text and files are never sent to any server, so you can safely process sensitive assets.
