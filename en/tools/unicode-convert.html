Frequently Asked Questions

      

        
What is a surrogate pair?

        
Characters at U+10000 and above (such as most emoji) cannot be represented by a single UTF-16 unit and require a pair of 16-bit surrogates (high surrogate + low surrogate). JavaScript strings use UTF-16 internally, so "😀" appears as two UTF-8 units; this tool lists them separately in the detail table.

      

      

        
What is the difference between UTF-8 bytes and UTF-16 units?

        
UTF-8 encodes a code point with 1 to 4 variable-length bytes, ideal for storage and transfer. UTF-16 uses 16-bit (2-byte) units: BMP characters take one unit, while supplementary-plane characters take two units (a surrogate pair). This tool shows both to help diagnose encoding issues.

      

      

        
How is the input format determined when decoding?

        
During decoding, the tool auto-detects by characteristics: contains &# → HTML entity, \u → JS escape, \x → UTF-8 byte escape, U+ → code point, % → percent encoding, and space-separated hex bytes → UTF-8 Hex. It then restores the original string.
