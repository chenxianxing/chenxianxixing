Frequently Asked Questions

Does the Mermaid editor need an internet connection?

No. All diagrams are rendered locally in your browser with the Mermaid library. Your code and diagrams are never uploaded to any server, which makes it safe for internal or sensitive workflows.

Which export formats are supported?

You can export the current diagram as an SVG vector image or a PNG bitmap. SVG scales without quality loss and stays editable, while PNG is handy for documents and slides.

Why did the diagram fail to render?

Usually it is a Mermaid syntax error, such as a missing semicolon, a wrong node connector, or an unsupported keyword. Fix the syntax following the error message below, then click Render.
