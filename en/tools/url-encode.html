URL Encode & Decode

Online URL encode/decode converter supporting four modes: encodeURIComponent, encodeURI, decodeURIComponent and decodeURI. Input is converted instantly and all processing is done locally in the browser.

Note: encodeURIComponent escapes all characters except letters, digits and - _ . ! ~ * ' ( ), which suits encoding URL parameter values; encodeURI keeps URL structure characters such as : / ? # & =, which suits encoding complete URLs. If an error is shown when decoding, the input is not a valid percent-encoded sequence.

Frequently Asked Questions

What is the difference between encodeURI and encodeURIComponent?

encodeURI is used to encode a complete URL and does not escape URL structure characters such as : / ? # & =; encodeURIComponent is used to encode URL parameter values and escapes all characters except letters, digits and - _ . ! ~ * ' ( ). Use encodeURI for an entire URL and encodeURIComponent for parameter values.

Is URL encoding necessary?

When a URL contains special characters such as Chinese characters, spaces, emoji or & # ?, encoding is required; otherwise it may cause request errors or abnormal parameter parsing. The Chinese text seen in the browser address bar is usually the result after encoding.

What should I do if decoding fails with an error?

decodeURIComponent throws a URIError when it encounters an invalid percent-encoded sequence (such as %zz or a lone %). Please check whether the input is a valid URL-encoded string, or try switching to decodeURI mode.
