Frequently Asked Questions

Is the randomness of this password generator secure?

This tool uses the browser built-in cryptographically secure random number generator crypto.getRandomValues with rejection sampling to avoid distribution bias, making it far safer than Math.random(). All passwords are generated on your device only and are never uploaded to any server.

What does Exclude look-alike characters mean?

Look-alike characters are symbols that are easily confused visually, such as 0 and O, 1 and l and I, as well as the vertical bar, backtick, single and double quotes, semicolon and colon. When checked, these characters are removed from the character set, making the generated passwords easier to copy by hand or read aloud, though this is not recommended for machine auto-verification.

How long does a password need to be to be secure?

As a rule, use at least 12 characters with multiple character types, and 16 or more for important accounts. This tool estimates entropy from the character pool size; the higher the entropy, the safer the password. Please use a different password for each site and keep them in a password manager.
