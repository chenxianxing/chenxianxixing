Frequently Asked Questions

Are drafts saved automatically?

Yes. Your edits are saved to browser localStorage in real time and are restored when you open the page again after refreshing or closing it. Click Clear Draft to delete the locally saved content.

Does the exported HTML file include styles?

Yes. The export generates a complete HTML document with basic typography styles embedded (headings, lists, code blocks, tables, quotes, etc.), so opening it in a browser gives a clean reading experience.

Will my document be uploaded?

No. All Markdown parsing and exporting is done locally in your browser; document content is only stored on your own device (localStorage) and is never sent to any server.
