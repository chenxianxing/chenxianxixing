Frequently Asked Questions

Is Base64 a form of encryption?

No. Base64 is only an encoding scheme that represents binary or text data as printable characters. It can be easily restored by anyone or any program and provides no confidentiality. It is commonly used to transmit binary data in text-only contexts such as email or DataURLs.

Why do Chinese or Emoji characters get garbled when encoding or decoding?

The native btoa function only supports Latin1 characters. This tool first uses TextEncoder to encode text into UTF-8 bytes before converting to Base64, so Chinese, Emoji and other characters are handled correctly without garbled output.

What is URL-safe mode used for?

Standard Base64 contains + and /, which get escaped in URLs and file names. URL-safe mode replaces + with - and / with _ and drops the padding equals signs, making it suitable for putting encoded results directly into links or parameters.
