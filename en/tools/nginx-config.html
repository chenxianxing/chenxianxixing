Frequently Asked Questions

      

        
Where should the generated config be placed?

        
On Debian/Ubuntu it usually goes to /etc/nginx/sites-available/ and is symlinked into /etc/nginx/sites-enabled/, or written directly as a .conf under /etc/nginx/conf.d/. After changes, validate with nginx -t, then gracefully reload with nginx -s reload.

      

      

        
What is the difference between a SPA (single-page app) and a static site?

        
A static site uses try_files $uri $uri/ =404; and returns 404 when a file is not found; a SPA uses try_files $uri $uri/ /index.html; to fall back all unknown paths to the entry index.html, handled by the front-end router, ideal for React, Vue and similar frameworks.

      

      

        
How does a reverse proxy pass through real client info?

        
The generator writes proxy_set_header Host, X-Real-IP, X-Forwarded-For and X-Forwarded-Proto so the backend can get the real client IP and protocol. With WebSocket enabled it also adds the Upgrade and Connection headers.
