HTML格式化

在线HTML处理工具，支持按层级缩进美化（2空格/4空格/Tab，属性可换行对齐）、压缩去注释与多余空白、HTML实体转义与反转义，并可检测未闭合标签。所有处理均在浏览器本地完成。

说明：美化按标签层级缩进；压缩保留 <pre>、<textarea>、<script> 内容原样；转义将 < > & 等转为 HTML 实体。每次处理都会检测标签闭合情况。

常见问题

压缩会破坏 <pre>、<textarea>、<script> 里的内容吗？

不会。压缩功能会完整保留 <pre>、<textarea>、<script> 标签内的原始内容（包括其中的空格与换行），只去除标签之间的多余空白与注释，因此代码块与脚本不会被误改。

标签未闭合检测是怎么工作的？

检测采用简单的栈匹配：遇到开始标签入栈，遇到对应结束标签出栈。若栈中残留标签或遇到无法匹配的结束标签，会提示具体的未配对标签名。自闭合标签（如 <img>、<br>）与 void 元素不参与匹配。

HTML 实体转义有什么用？

在网页中展示 HTML 源码时，需将 <、>、&、"、' 转为对应实体，否则会被浏览器当作标签解析。转义用于“显示代码”，反转义则用于把实体还原为原始字符。
