HTML格式化

在线HTML处理工具，支持按层级缩进美化（2空格/4空格/Tab，属性可换行对齐）、压缩去注释与多余空白、HTML实体转义与反转义，并可检测未闭合标签。所有处理均在浏览器本地完成。

标签闭合检测

    说明：美化按标签层级缩进；压缩保留 <pre>、<textarea>、<script> 内容原样；转义将 < > & 等转为 HTML 实体。每次处理都会检测标签闭合情况，并指出问题所在的行号，点击提示可定位到源码对应行。

    常见问题

    压缩会破坏 <pre>、<textarea>、<script> 里的内容吗？

    不会。压缩功能会完整保留 <pre>、<textarea>、<script> 标签内的原始内容（包括其中的空格与换行），只去除标签之间的多余空白与注释，因此代码块与脚本不会被误改。

    标签未闭合检测是怎么工作的？

    检测会逐字符扫描文档结构，跳过注释、DOCTYPE 与 CDATA，并把 <script>、<style>、<pre>、<textarea> 内部的文本当作纯文本处理，其中的 < 与 > 不会被误判成标签，所以 JS 里的 a < b 比较或 HTML 字符串不会造成误报。发现未闭合的开始标签或多余的结束标签时，会直接给出所在行号，点击结果即可定位到源码对应行。HTML5 中允许省略的结束标签（如 </li>、</p>、</body>）不视为错误。

    HTML 实体转义有什么用？

    在网页中展示 HTML 源码时，需将 <、>、&、"、' 转为对应实体，否则会被浏览器当作标签解析。转义用于“显示代码”，反转义则用于把实体还原为原始字符。
