SQL Dump Generator

Online INSERT statement generator that builds INSERT INTO statements from a table name plus a JSON array or CSV/TSV data, with multi-value batch inserts, column selection, backquoted fields and NULL handling.

Frequently Asked Questions

Which data input formats are supported?

JSON arrays of objects are supported, as are CSV/TSV tables with a header row separated by commas or tabs; the tool detects the delimiter automatically and extracts the column names.

What does Rows per INSERT mean?

It determines how many rows of data are combined into the multi-value form of a single INSERT statement (e.g. one statement per 10 rows). Smaller values produce more statements, larger values produce longer single statements; choose based on your database limits.

How are single quotes inside strings handled?

The tool automatically writes single quotes inside strings as two single quotes ('') to comply with the SQL standard. Empty strings or missing values are converted to the NULL keyword when Output NULL for empty values is enabled.
