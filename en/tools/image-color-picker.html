Frequently Asked Questions

Can the picker grab any color from a web page?

This tool can only pick colors from images you upload to this page; it cannot directly sample colors of other web pages in the browser. To pick a color from anywhere on the screen, use your operating system's built-in screen color picker.

How does "Extract dominant colors" work?

The tool first shrinks the image so its longest side is within 160 pixels to reduce computation, then compresses each pixel's R, G and B channels to 16 levels (right shift by 4 bits) for bucket counting. The most frequent colors are the dominant colors.

What is manual HEX lookup for?

When you only have a HEX value (for example a color copied from a design mockup), the lookup quickly converts it to the corresponding RGB and HSL values, convenient for use across different tools or code without opening another conversion page.
