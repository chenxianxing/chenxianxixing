CSV to JSON

Online CSV and JSON converter supporting multiple delimiters and RFC4180 quoted field parsing. All data processing is done locally in your browser and nothing is uploaded.

Note: Parsing follows the RFC4180 standard. A field wrapped in double quotes may contain delimiters, line breaks and double quotes (two consecutive double quotes represent one quote). Always wrap fields containing special characters in quotes.

Note: An array of objects automatically uses the first-row keys as the header; a 2D array is output row by row. Fields containing delimiters, quotes or line breaks are automatically quoted and escaped.

Frequently Asked Questions

What if a field contains a comma or a line break?

This tool follows the RFC4180 standard: a field wrapped in double quotes may contain delimiters, line breaks and double quotes (doubling represents one quote). Improper wrapping will cause parsing misalignment, so always quote fields that contain special characters.

What does Use first row as header mean?

When checked, the first CSV row is treated as the field names and the output is an array of objects keyed by the header; when unchecked, the output is a 2D array (each element is the array of values for one row), which suits header-less raw data.

What should I do when parsing fails on a specific row?

The error message points to the specific line number. The most common cause is an unpaired quote. Check whether a closing quote is missing on that line, or whether quotes inside a field are written as two double quotes as required.
