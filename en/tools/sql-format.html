SQL Formatter

Online SQL beautifier and minifier supporting keyword uppercasing, main clause line breaks, AND/OR indentation, comma line breaks and custom indentation, with strings and comments preserved unchanged. Everything is processed locally in your browser.

Note: the tool recognizes common SQL keywords and uppercases them uniformly, breaks main clauses (SELECT/FROM/WHERE/JOIN, etc.) onto new lines and indents AND/OR; single-quoted strings, double-quoted identifiers and comments are preserved unchanged.

Frequently Asked Questions

Are SQL keywords uppercased automatically?

Yes. The tool recognizes common SQL keywords (such as SELECT, FROM, WHERE and JOIN) and uppercases them uniformly, while identifiers such as table and column names keep their original casing.

Are strings and comments modified?

No. Single-quoted strings, double-quoted identifiers and -- and /* */ comments are all preserved unchanged; they are neither reformatted nor broken.

What is the minify mode for?

Minify mode collapses SQL into a single line and removes extra whitespace. It is commonly used for logs, configuration or transmission, making copying and comparison easier, and keywords are uppercased as well.
