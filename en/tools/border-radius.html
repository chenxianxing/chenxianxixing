Frequently Asked Questions

What is the shorthand order of border-radius?

The four values of border-radius correspond to top-left, top-right, bottom-right and bottom-left (clockwise). With only two values, the first applies to the top-left/bottom-right and the second to the top-right/bottom-left (diagonal corners match). For elliptical radii, separate the horizontal and vertical values with a slash, e.g. 10px / 20px.

What is the difference between px and % units?

px is a fixed pixel radius that does not change with the container size, while % is a percentage relative to the side the radius sits on: for example, 50% yields a perfect circle on a square and an ellipse on a rectangle. Prefer % for responsive layouts or perfect circles.

How do I create elliptical corners (leaf or petal shapes)?

Use the slash syntax to specify the horizontal and vertical radii separately, e.g. border-radius: 50% 50% 50% 0 / 60% 60% 40% 40%. The advanced mode of this tool lets you adjust both values for each corner directly to create such effects.
