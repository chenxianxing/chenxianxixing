Frequently Asked Questions

Which WKT geometry types does the tool support?

POINT, LINESTRING, POLYGON, MULTIPOINT, MULTILINESTRING, MULTIPOLYGON and GEOMETRYCOLLECTION are supported. Z, M and ZM dimension markers after coordinates (3D / measured values) are also recognized, so basic 2D and common 3D formats are parsed correctly.

Is the output GeoJSON standards compliant?

The output strictly follows RFC 7946: it includes type, coordinates (or geometries for geometry collections) and an optional top-level bbox field. It can be used directly with map libraries such as Leaflet, Mapbox and OpenLayers, or in geodata processing pipelines.

What happens if the input format is wrong?

Parsing first checks bracket balance and coordinate values. If brackets do not match or coordinates are not valid numbers, the error message will point to the approximate location so you can quickly find and fix the WKT text.
