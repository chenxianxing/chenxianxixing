常见问题

      

        
生成的配置应该放在哪里？

        
在 Debian/Ubuntu 上通常放到 /etc/nginx/sites-available/ 并通过软链接到 /etc/nginx/sites-enabled/；或直接写入 /etc/nginx/conf.d/ 下的 .conf 文件。修改后用 nginx -t 校验，再用 nginx -s reload 平滑重载。

      

      

        
SPA（单页应用）和静态站有什么区别？

        
静态站使用 try_files $uri $uri/ =404;，找不到文件即返回 404；SPA 使用 try_files $uri $uri/ /index.html;，将所有未知路径回退到入口 index.html 由前端路由处理，适合 React、Vue 等前端框架。

      

      

        
反向代理如何透传真实客户端信息？

        
生成器会写入 proxy_set_header Host、X-Real-IP、X-Forwarded-For 与 X-Forwarded-Proto，使后端能拿到真实客户端 IP 与协议。启用 WebSocket 后还会补充 Upgrade 与 Connection 头。
