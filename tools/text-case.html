大小写转换

在线英文字母大小写与命名法转换工具，支持全部大写、全部小写、每词首字母大写、句首大写、反转大小写，以及 camelCase、PascalCase、snake_case、kebab-case、CONSTANT_CASE，可多选按序组合，实时预览。

说明：多种模式可同时勾选，将按“全部大写 → 全部小写 → 每词首字母 → 句首 → 反转 → camel → pascal → snake → kebab → 常量”的顺序依次应用。命名法模式会先按词拆分（含驼峰边界与符号分隔）再组合。

常见问题

可以把多种转换组合起来使用吗？

可以。所有模式按钮都可多选，转换会按照页面列出的顺序依次应用。例如先选“全部小写”再选“snake_case”，可把任意文本规整为下划线命名。

camelCase 和 PascalCase 有什么区别？

camelCase（小驼峰）首单词首字母小写，后续单词首字母大写，例如 myVariableName；PascalCase（大驼峰）每个单词首字母都大写，例如 MyVariableName。两者常用于不同编程语言的命名约定。

CONSTANT_CASE 是什么？

CONSTANT_CASE 又称大写常量命名，所有字母大写、单词之间用下划线分隔，例如 MAX_COUNT。常见于常量、枚举值或配置项的命名。
