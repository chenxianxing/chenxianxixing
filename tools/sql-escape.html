SQL转义

在线 SQL 字符串转义与 IN 列表生成工具，支持单引号加倍、反斜杠与控制字符转义、转义还原，以及多行文本一键生成 IN 列表。

说明：转义会将 ' 变成 ''，\ 变成 \\，换行/回车/制表符/NUL 变为 \n \r \t \0；还原则反向处理。勾选包裹单引号会把整段结果用单引号括起来。

说明：自动去除空行与首尾空白，为每项加上单引号并以逗号连接成单行，可直接用于 IN (...) 条件。

常见问题

为什么要对 SQL 字符串做转义？

字符串中的单引号会破坏 SQL 语句结构，甚至引发 SQL 注入。将单引号写成两个单引号（''）是最基础的转义方式，可确保字符串被数据库正确解析。

换行、制表符等控制字符如何转义？

工具会把实际的换行、回车、制表符与 NUL 字符分别转义为 \n、\r、\t、\0 形式的文本，并把反斜杠本身转义为 \\，便于安全地写入 SQL 语句。

IN 列表生成有什么用？

把每行一个的取值自动整理成 'a','b','c' 的逗号分隔形式，可直接粘贴进 IN (...) 条件，自动去除空行并加引号。
