CSV转JSON

在线 CSV 与 JSON 互相转换工具，支持多种分隔符与 RFC4180 引号字段解析，所有数据处理均在浏览器本地完成，不上传任何内容。

说明：解析支持 RFC4180 规范，被双引号包裹的字段内可包含分隔符、换行与双引号（连续两个双引号表示一个引号）。若字段含特殊字符，请务必使用引号包裹。

说明：对象数组会自动以首行键作为表头；二维数组则直接按行输出。含分隔符、引号或换行的字段会自动加引号转义。

常见问题

字段中含有逗号或换行怎么办？

本工具遵循 RFC4180 规范，使用双引号包裹的字段可以包含分隔符、换行和双引号（双写表示一个引号）。未正确包裹会导致解析错位，建议始终为含特殊字符的字段加引号。

首行作为表头是什么意思？

勾选后，CSV 第一行会被当作字段名称，输出为以表头为键的对象数组；不勾选则输出为二维数组（每个元素是一行的值数组），适合无表头的纯数据。

解析报错提示某行有问题怎么办？

报错信息会指出具体行号，最常见的原因是引号未成对闭合。请检查该行是否遗漏了结束引号，或字段内引号是否按规范写成两个双引号。
