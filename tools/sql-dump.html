SQL Dump生成器

在线 INSERT 语句生成工具，根据表名与 JSON 数组或 CSV/TSV 数据一键生成 INSERT INTO 语句，支持多值批量插入、列勾选、字段反引号与空值处理。

常见问题

支持哪些数据输入格式？

支持 JSON 对象数组，以及带表头、以逗号或制表符分隔的 CSV/TSV 表格，工具会自动识别分隔符并提取列名。

每条 INSERT 行数是什么意思？

表示把多少行数据合并到一条 INSERT 语句的多值写法中（如每 10 行一条）。数值越小语句越多，越大则单条语句越长，可据数据库限制自行选择。

字符串里的单引号会怎么处理？

工具会把字符串中的单引号自动写成两个单引号（''）以符合 SQL 规范，空字符串或缺失值在开启「空值输出 NULL」时会转为 NULL 关键字。
