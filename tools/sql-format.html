SQL格式化

在线 SQL 美化与压缩工具，支持关键字大写、主子句换行、AND/OR 缩进、逗号换行与自定义缩进，字符串与注释原样保留，全程浏览器本地处理。

说明：工具会识别常见 SQL 关键字并统一大写，主子句（SELECT/FROM/WHERE/JOIN 等）换行，AND/OR 缩进显示；单引号字符串、双引号标识符与注释内容均原样保留。

常见问题

SQL 关键字会自动大写吗？

是的，工具会识别常见的 SQL 关键字（如 SELECT、FROM、WHERE、JOIN 等）并统一转为大写，而表名、列名等标识符会保持原有大小写不变。

字符串和注释会被修改吗？

不会。单引号字符串、双引号标识符以及 -- 和 /* */ 注释内容都会被原样保留，不会被格式化或破坏。

压缩模式有什么用？

压缩模式会把 SQL 折叠为单行并去除多余空白，常用于日志、配置或传输场景，便于复制与比对，关键字同样会大写。
