常见问题

      

        
数组里元素类型不一致时会生成什么？

        
工具会遍历数组中的每个元素并合并它们的字段与类型。当同一位置出现不同类型时，会生成联合类型，例如 [1, "a"] 会推断为 number | string；空数组则输出 any[]（或对应语言的可空/任意类型）。

      

      

        
嵌套对象会如何处理？

        
嵌套对象会被递归处理并生成带名字的子类型：TypeScript 会生成独立的 interface 或 type，Go 生成独立的 struct 并通过 json 标签保留原字段名，Python 生成独立的 TypedDict，Rust 生成独立的 struct 并附带 serde 派生。

      

      

        
键名不是合法标识符时怎么办？

        
TypeScript 会对非法标识符键名加引号（如 "foo-bar"）；Go 会把字段名转换为 PascalCase 并用 json 标签保留原键；Python 与 Rust 转换为 snake_case。这样生成的代码既合法又能在序列化时对应原始 JSON 键。
