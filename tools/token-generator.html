Token生成器

在线随机令牌/密钥/API Key 生成工具，使用浏览器 crypto 安全随机数生成，支持 Hex、Base64、Base64URL 多种格式与批量生成，所有计算均在本地完成，不会上传。

🔒 安全提示：所有 Token 仅在你的浏览器本地生成，不会经过任何网络传输或服务器存储。生成的密钥请妥善保存，一旦泄露请立即轮换。不要在公开代码仓库或日志中明文保存。
各格式适用场景：
• Hex（十六进制）：兼容性最好，可直接存入数据库或打印在日志，但长度是原始字节的 2 倍，适合用作随机盐值、设备指纹。
• Base64：体积比 Hex 小约 1/3，常用于配置文件或网络传输，但不适合直接放进 URL。
• Base64URL：将 + 和 / 替换为 - 和 _，并去掉末尾填充 =，专用于 URL、JWT 载荷或文件名，不会被转义。

常见问题

Hex、Base64 和 Base64URL 该怎么选？

Hex（十六进制）兼容性好、可直接用于数据库或日志，但体积比原始字节大 1 倍；Base64 体积更小，常用于配置或传输；Base64URL 把 + 和 / 替换为 - 和 _，并去掉填充 =，适合放在 URL、JWT 或文件名中，避免被转义。

生成的 Token 安全吗？

本工具使用浏览器内置的 crypto.getRandomValues 密码学安全随机数生成器生成，不可被预测。所有内容仅在本地生成，不会上传。生成后请妥善保存，密钥一旦泄露应立刻轮换。

Token 需要多长才安全？

用于会话令牌或 API Key 推荐至少 32 字节（256 位）的随机熵；短期或低敏感场景 16 字节也可接受。输出长度越长，暴力破解难度越高。请避免重复使用同一 Token 用于不同用途。
