常见问题

工具支持解析哪些格式的输入？

支持完整 URL（会自动提取问号后的 query 部分）、带问号的 query string（如 ?a=1&b=2）以及不带问号的纯参数串（如 a=1&b=2）。URL 中的 #hash 片段会被单独保留，不会被当作参数。

编码开关起什么作用？

开启后，重组 URL 时每个参数值都会经过 encodeURIComponent 编码，适合直接用于请求；关闭后则原样拼接，适合查看或构造带中文/特殊字符的可读链接。参数表中也会标注每一行当前是否为 URL 编码状态。

粘贴进去的 URL 含 #hash 会怎样？

工具会正确地把 # 之后的部分识别为 hash（片段标识符）并单独保留，不会混入参数。重组后的 URL 也会把 hash 原样拼接在末尾。
