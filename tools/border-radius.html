常见问题

border-radius 的简写顺序是怎样的？

border-radius 四个值依次对应：左上、右上、右下、左下（顺时针）。若只写两个值，则第一个表示左上/右下、第二个表示右上/左下（对角相同）。椭圆圆角可用斜杠分隔水平与垂直半径，如 10px / 20px。

px 和 % 单位有什么区别？

px 是固定的像素半径，结果随容器尺寸固定；% 是相对圆角所在边的百分比，例如 50% 在正方形上得到正圆，在长方形上得到椭圆。需要响应式或正圆效果时优先使用 %。

如何实现椭圆圆角（叶子、花瓣形）？

使用斜杠语法分别指定水平半径和垂直半径，例如 border-radius: 50% 50% 50% 0 / 60% 60% 40% 40%。工具的高级模式可直接调节每个角的水平、垂直双值来生成这类效果。
