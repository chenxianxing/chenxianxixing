常见问题

JWT 由哪几部分组成？

JWT（JSON Web Token）由三段用英文点号「.」连接而成：第一段是 Header（头部，声明算法与类型），第二段是 Payload（载荷，存放业务与标准声明），第三段是 Signature（签名，由前两段用密钥签名得到）。解码前两段可查看内容，但签名需在服务端用密钥校验。

exp / iat / nbf 这些时间字段是什么？

它们都是 Unix 秒级时间戳：exp 表示过期时间、iat 表示签发时间、nbf 表示在此时间之前不可用（Not Before）。本工具会将其换算成可读时间，并对 exp、iat、nbf 显示是否已过期 / 是否生效的徽标。

在网页里粘贴 JWT 安全吗？

本工具所有解析都在浏览器本地完成，不会把 Token 上传到任何服务器。但仍建议在不可信的第三方站点谨慎粘贴包含敏感信息（如身份、权限）的 Token。请仅在可信的本地工具中解析。
