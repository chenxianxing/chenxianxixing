常见问题

JSON 校验报错会给出位置吗？

会。当 JSON 语法有误时，工具会解析错误信息并换算出具体的「第几行第几列」，帮助你快速定位问题所在。

路径查询支持什么格式？

支持形如 $.store.book[0].title 的路径写法：对象属性用点号，数组元素用方括号索引。输入路径后点击定位即可高亮对应节点。

可以直接复制某个节点的值或路径吗？

可以。将鼠标悬停在任意节点行上，会出现「复制值」和「复制路径」两个按钮，分别复制该节点的 JSON 值与完整路径字符串。
