常见问题

为什么 SHA 系列在本地双击打开（file://）时无法计算？

SHA 系列使用浏览器 Web Crypto 接口（crypto.subtle），该接口仅在安全上下文中可用（https 或 http://localhost）。如果你直接双击打开网页（地址栏为 file://），浏览器会禁用 crypto.subtle。解决办法是通过本地服务器访问，例如在目录内执行 python -m http.server 后用 http://localhost 打开。

MD5 安全吗？还能用来做什么？

MD5 已被证明存在碰撞漏洞，不可用于安全签名或密码存储，但依然适合做普通文件完整性校验（如下载文件比对）或非安全场景的摘要。本工具的 MD5 为纯 JavaScript 实现，无需任何外部库。

HMAC 和普通的哈希有什么区别？

HMAC（基于哈希的消息认证码）在哈希计算中引入了密钥，只有持有相同密钥的双方才能验证数据完整性，可防止篡改。普通哈希没有密钥，任何人都能重新计算。HMAC 常用于接口签名、请求校验等场景。
