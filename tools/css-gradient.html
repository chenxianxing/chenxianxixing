CSS渐变生成器

在线 CSS 渐变代码生成工具，支持线性、径向、圆锥三种渐变类型，可视化调节角度、形状、位置与多色标，实时预览并一键复制可直接使用的 CSS 代码。

说明：色标位置为该颜色在渐变中所占的百分比，可点击取色器或直接输入 HEX。复制的 CSS 为 background 属性，直接粘贴到目标元素样式即可生效。

常见问题

线性渐变和径向渐变有什么区别？

线性渐变沿一条直线方向过渡（可通过角度控制方向），适合营造斜向或上下过渡；径向渐变从中心向外呈圆形或椭圆形扩散，适合模拟光晕、按钮高光等效果。圆锥渐变则绕中心点旋转着色。

生成的CSS代码如何直接使用？

将工具生成的 background 属性复制后粘贴到目标元素的CSS规则中即可。绝大多数现代浏览器均原生支持 linear-gradient、radial-gradient 与 conic-gradient。

可以设置多少个颜色停靠点？

颜色停靠点数量没有固定上限，工具默认提供两个，可随时点击“添加色标”增加，也可以删除多余色标，最少保留两个以保证渐变有效。
