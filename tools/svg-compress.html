常见问题

SVG压缩会破坏图形吗？

本工具只移除注释、声明、metadata以及 Inkscape / Sodipodi 等编辑器专有属性，并对坐标数值做四舍五入，不会改动 path 的命令字母（M、C、L 等）与图形结构，因此通常不影响渲染效果。建议你压缩后预览确认，也可调整数值精度以平衡体积与精度。

数值精度选多少合适？

精度表示小数点后的位数。图标等小尺寸图形选 1~2 位通常足够且体积更小；需要保留细节的插画可选 2~3 位。精度为 0 会取整坐标，可能明显改变形状，请谨慎使用。

压缩后的文件会上传吗？

不会。所有解析、压缩与下载都在你的浏览器本地完成，文本与文件不会发送到任何服务器，可放心处理敏感素材。
